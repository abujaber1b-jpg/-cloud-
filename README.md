# لعبة القضايا
1. ارفع المجلد على GitHub ثم في Render: New > Blueprint (يقرأ render.yaml) أو Web Service (Build: npm install، Start: npm start).
2. افتح الرابط > "أنا المقدم" > اختر عدد المجموعات > شارك رابط كل مجموعة.
محلياً: npm install && npm start ثم http://localhost:3000
القضايا في cases.js (الحقول: t عنوان، e أيقونة، s القصة، c الجاني، m السبب، x التناقضات). الحالة في الذاكرة، إعادة تشغيل الخادم تمسح الغرف.
